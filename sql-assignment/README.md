# Week 2 - SQL-Based Sales Analysis

## Objective

Analyze Superstore sales data using SQL with filtering, aggregation, and business queries.

## Dataset

Sample Superstore Dataset

## Tools Used

- SQL
- MySQL Workbench

## Tasks Performed

- Loaded the dataset into MySQL.
- Explored the table schema and sample data.
- Applied WHERE filters on region, category, date, and sales.
- Used GROUP BY for sales, quantity, and average calculations.
- Sorted and limited results using ORDER BY and LIMIT.
- Solved business use cases such as monthly sales trends, top customers, and duplicate checks.
- Validated data using row counts and data quality checks.

## Files Included

- sales_analysis.sql
- Query result screenshots

## Key Insights

- Identified top-performing customers based on sales.
- Analyzed monthly sales trends.
- Used SQL aggregation functions to summarize business performance.
- Performed data validation to ensure data quality.

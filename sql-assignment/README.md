# 📊 Week 2 - SQL-Based Sales Analysis

## 📌 Objective

The objective of this assignment was to analyze sales data using SQL by applying filtering, aggregation, sorting, and business-oriented queries to extract meaningful insights from the Superstore dataset.

## 🛠️ Tools & Technologies

* SQL
* MySQL Workbench
* Git & GitHub

## 📂 Dataset

**Sample Superstore Dataset**

## ✅ Tasks Performed

* Imported the Superstore dataset into a MySQL database.
* Explored the table structure and examined sample records.
* Applied `WHERE` filters based on region, category, sales, and order date.
* Used aggregate functions such as `SUM()`, `AVG()`, and `COUNT()` for data analysis.
* Performed grouping using `GROUP BY` to summarize sales and quantity.
* Sorted and limited query results using `ORDER BY` and `LIMIT`.
* Solved business use cases including monthly sales trends, top customers, and duplicate record checks.
* Validated dataset quality using row count and duplicate verification queries.
